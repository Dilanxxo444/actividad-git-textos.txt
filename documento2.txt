Notas sobre el trabajo con Git:
Al comienzo fue un poco enredado el tema de las llaves, los permisos y la consola, pero ya con la practica de git add, git commit y git push se vuelve un proceso bastante mecanico.

Puntos a tener en cuenta:
1. Poner mensajes de commit breves y directos para no perder tiempo adivinando que se cambio.
2. Es mucho mas rapido trabajar directo desde la terminal que subir las cosas a mano por la pagina.
3. Sirve bastante para tener respaldo de documentos e informes sin llenar el computador de copias repetidas.

Queda pendiente revisar los proximos ejercicios de la materia.
